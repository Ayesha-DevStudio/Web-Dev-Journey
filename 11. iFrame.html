iFrame

An iframe allows us to embed webpages, other websites, videos, or maps on our webpage.

1. Embedding our own webpage

Syntax:
<iframe src="filename.html" name="Myframe" width="500" height="300"></iframe>

We can add query parameters to YouTube URLs such as:

  • autoplay=1 (automatically plays video; 0 disables it)
  • mute=1 (mutes video when played; 0 enables sound)
  • loop=1 (restarts video automatically; 0 stops when finished)
  • controls=1 (shows control buttons; 0 hides controls)

5. Adding an Audio File

Now I want to add local audio from my device onto the webpage. Here is how to do that using the syntax below:



Syntax Details:
<audio> tag: Tells the browser it is an audio file.
source src: Specifies the audio file path.
type: Specifies the MIME type (e.g., audio/mpeg for MP3).

Attributes of audio tag:

  • controls: Shows playback controls (play, pause, volume).
  • autoplay: Automatically plays audio on page load.
  • loop: Automatically replays audio when finished.
  • muted: Mutes audio by default.
