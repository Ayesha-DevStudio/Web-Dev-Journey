All Input Types Explained

1. Button

Used to create a clickable button.

2. Checkbox

Allows the user to select one or more options.

I agree to the terms and conditions.

3. Color

Allows the user to select a color picker.

Choose color of your choice.

4. Date

Used for selecting a date from a calendar popup.

Choose your birth date.

5. DateTime-Local

Used to select both date and time without time zone.

Choose your preferred date and time for interview.

6. Email

Used for entering email addresses with automatic validation.

Enter your Email.

7. File

Allows the user to select and upload files from their device.

Upload document.

8. Hidden

Only visible to programmer to store background data.

9. Image

Uses an image as a graphical submit button.

10. Month

Allows selecting a specific month and year.

Choose Month of your Graduation.

11. Number

Restricts user input strictly to numerical values.

Enter your Age.

12. Password

Masks entered characters to securely conceal passwords.

Enter password.

13. Radio

Allows selecting only one single option from a group.

Male Female

14. Range

Displays a slider control to select a value within a range.

Adjust volume level.

15. Reset

Will reset whatever input values you write in the form back to default.

16. Search

Used for search input fields.

Search query.

17. Submit

Used to send form data to a server.

To submit an application.

18. Tel

Used for entering telephone numbers.

Enter your telephone number.

19. Text

To specify that user input is single-line text type.

Enter your name.

20. Time

For time-based input without time zone.

Choose time.

21. URL

For entering web addresses with validation.

Enter website URL.

22. Week

For week-based date input (week number and year).

Choose week.
