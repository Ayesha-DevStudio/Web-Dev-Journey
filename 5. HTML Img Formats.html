HTML Image Formats

First let's talk about image attributes
img = tag of image. Only contains opening tag.
alt = It gives description the image in case image is not displayed.
title = It tells what is in image when we hover mouse over it.
width = Can be used to specify width of image like 20% or 200px.
height = Can be used to specify height of image like 20% or 200px.

How to add Images in the HTML document


First Method (When image is in the same folder as your html document).

Simply write the image name. its extension.

Second Method (When image is in a website).

Right click the image and copy its image address

To convert image to link we can put the image block in href tags.
Let's suppose I want the user to be directed to Pinterest if he/she clicks the 2nd image so I put it in href block. Now check out clicking the above image.
