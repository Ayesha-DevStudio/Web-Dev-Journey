Input Attributes Explained

1. Pattern

It restricts the user to write the input in desired pattern.

2. Placeholder

It places a temporary text in the input guiding the user what to input.

3. Required

It requires the user to write in the field by displaying it as required.

4. Step

It specifies the step as writing input as multiple of the number given. e.g. The following has step of 5 so you can only write values that are multiple of 5.

5. Autofocus

It automatically focuses the cursor to the input field.

6. Width & Height

It specifies the width and height of the image.

7. Autocomplete

It shows suggestions to user based on previous inputs. It has two values: on and off.




Input Type Attributes Explained

1. Value

Lets a programmer add a value in input field.

2. Readonly

Lets us turn the input field to a readonly field which cannot be edited.

3. Disabled

It disables the input so the input cannot be selected again.

4. Size

It specifies the size of input area.

5. Maxlength

It specifies the max characters a user can put in the input field. It is mostly used in password input or PIN.

6. Min

It specifies the minimum digit a user can input. For example let's put it for 5.

7. Max

It specifies the maximum digit a user can input. For example let's put it for 100.

8. Multiple

It allows user to choose multiple files in case of file input.
