Using Marquee Tag

Anything written in Marquee tag keeps moving in website.

Now let's discuss the important attributes of Marquee

1. marquee is used for marquee tag
2. scrollamount is used to tell the speed of movement. I prefer this number to be 15.
3. direction tells which direction: left(default), right, up, down.
4. onmouseover="this.stop()" stops the moving text when cursor is hovered over it.
5. onmouseleave="this.start()" resumes the moving text when cursor is moved away from it.

Some Important tags

The tag &nbsp; creates a space between joined words e.g. Ayesha Faisal.
The tag &copy; creates the copyright symbol e.g. Copyright ©.
The tag &times; creates a close sign e.g. Close ×
The tag <span> is used if we want to style specific words in the sentence.
The tags class and id are also used for specific styling.
