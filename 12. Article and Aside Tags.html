Using Base and Dialog Tags

Base Tag

To set a base path for relative URLs (such as images in a folder), we use the <base> tag inside the <head> element, e.g., <base href="images/">.

Dialog Tag

In websites, pop-up dialog boxes and modals are created using the <dialog> tag.
