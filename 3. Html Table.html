Creating Lists Using HTML

There are 3 types of lists in HTML Lets discuss them one by one.

1. Unordered List(ul)
Unordered lists can be made by ul tag. while li describes list items.

  • C++
  • Java
  • Python
  • Ruby

Now unordered lists uses 4 types of bullets which can be defined in the ul tag such as circle, disc(default), square and none. I have used square in my list.

Syntax = ul type="square"


2. Ordered List(ol)
Ordered lists can be made by ol tag. while li describes list items. 5 Types of bullets in ol

  1. Type="A" will generate bullets of A, B, C...
  2. Type="a" will generate bullets of a, b, c...
  3. Type="I" will generate roman counting bullets of I, II, III...
  4. Type="i" will generate roman counting bullets of i, ii,...
  5. Type="1" will generate bullets of 1, 2, 3...

Now you can also start ordered lists from any number for that we use start="11" It will start bullets from 11th term of prescribed bullets. I have used 11 in my list.



Syntax = ol type="1" start="11"




3. Descriptive List(dl)
Descriptive lists can be made by dl tag. while dt describes descriptive term and dd describes descriptive definition.
